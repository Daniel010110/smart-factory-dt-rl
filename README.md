# smart-factory-dt-rl

A research-oriented Python project for a smart factory digital twin simulator focused on bottleneck prediction and reinforcement learning-based AGV optimization.

This repository is currently at the initial skeleton stage. The MVP simulation target is a 2D factory flow:

```text
Input -> ProcessA -> ProcessB -> ProcessC -> Output
```

The first milestone is intentionally small:

- 1 to 3 AGVs
- Job generation
- Process queues with fixed processing times
- AGV transport tasks
- FIFO and nearest-job baseline policies
- Step-level logging
- Future extension points for bottleneck prediction and a Gymnasium-style RL environment

## Project Structure

```text
config/                 Default simulation configuration
data/logs/              CSV logs generated by simulations
reports/                Research notes and generated reports
results/figures/        Generated plots
results/tables/         Generated result tables
scripts/                Command-line entry points
src/
  logging_utils/        Simulation logging helpers
  policies/             AGV dispatch policies
  simulator/            Core factory simulation entities
  utils/                Config and reproducibility utilities
  visualization/        Plotting helpers
tests/                  Skeleton tests
```

## Quick Start

```bash
python -m venv .venv
pip install -r requirements.txt
python scripts/run_simulation.py
python scripts/compare_policies.py
pytest
```

## Current Scope

The current codebase provides safe, minimal class skeletons and simple placeholder behavior. It does not yet implement complex path planning, collision avoidance, 3D simulation, bottleneck prediction models, or reinforcement learning dependencies.
